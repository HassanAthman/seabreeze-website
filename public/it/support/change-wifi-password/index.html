Cambia nome e password del WiFi

Fallo da un telefono o computer collegato al WiFi del router.

Circa 3 minuti

Prima di iniziare: collega il telefono al WiFi del router.

  1. 1

    Apri Chrome o un altro browser

    Search or type web address
  2. 2

    Scrivi 192.168.1.1 e aprilo

    Si apre la pagina delle impostazioni del router.
